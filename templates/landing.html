End-to-End System

Machine Learning Pipeline

Engineered from raw financial registries into high-precision, low-latency scoring microservices.

01

Data Ingestion

Cross-matching 438,000+ raw application records and credit history registries across shared ID keys.

02

EDA & Cleaning

Deduplication, categorical label encoding, imputation of missing occupations, and outlier boundaries.

03

Feature Engineering

Computing credit history windows, vintage seasoning, and combined family dependency indices.

04

Cost-Sensitive Training

Balancing class weights across the 87:13 non-default skew to minimize false approvals and credit risk.

05

Serverless Edge API

Optimized lightweight serialized model deployment on Vercel Edge with instantaneous inference.
